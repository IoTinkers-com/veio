# DS-0010 — OCHA HDX Venezuela administrative boundaries (COD-AB)

**Bottom line:** Official subnational boundaries (admin 0–3) sourced from INE, published by OCHA on HDX. Fully usable with attribution.

## Core
- Provider / URL: OCHA FISS (source: Instituto Nacional de Estadística) · https://data.humdata.org/dataset/cod-ab-ven (accessed 2026-10-04)
- License: CC BY-IGO (Creative Commons Attribution for Intergovernmental Organisations) · Attribution required: yes — OCHA/INE credit per CC BY-IGO · Modification: yes · Redistribution: yes
- Coverage: Venezuela admin 0–3: 25 states, 336 municipalities, 1,135 parishes · Temporal: version reviewed 2025-01-17 · Resolution: vector boundaries · Update: yearly
- Format / API: SHP, GeoJSON, GDB, XLSX · API no (direct download)
- Quality & limitations: Dependencias Federales admin-2/3 units are placeholders, not real subdivisions; boundaries carry no position on any border dispute
- Relevance to MVP (0–5): 3 — basemap and geo-enrichment for Atlas and dossiers
- Status: open
