# DS-0003 — Landsat 8/9 (USGS)

**Bottom line:** Public-domain optical archive for historical baselines back to 1972 (all sensors). Fully usable.

## Core
- Provider / URL: USGS · https://earthexplorer.usgs.gov (accessed 2026-10-04)
- License: public domain (US Government work; no restrictions on use or redistribution) · Attribution required: not required, requested — cite USGS as source · Modification: yes · Redistribution: yes
- Coverage: global · Temporal: 1972–present (all sensors); L8 2013-, L9 2021- · Resolution: 30 m multispectral (15 m pan) · Update: 16-day per satellite (~8-day combined)
- Format / API: GeoTIFF (Collection 2 L1/L2) · API yes (M2M, EarthExplorer, cloud buckets)
- Quality & limitations: coarser and less frequent than Sentinel-2; L2 surface reflectance preferred for indices
- Relevance to MVP (0–5): 4 — free long archive for pre-2015 baselines
- Status: open
